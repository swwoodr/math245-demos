📐 Finding eigenvalues and eigenvectors by hand ▼

$A\mathbf{v} = \lambda\mathbf{v}$ with $\mathbf{v}\neq\mathbf{0}$ means $(A-\lambda I)\mathbf{v}=\mathbf{0}$ has a nonzero solution, so $A-\lambda I$ must be singular:

$$\det(A-\lambda I) = \lambda^2 - (a+d)\,\lambda + (ad-bc) = \lambda^2 - T\lambda + D = 0.$$

The roots are $\lambda = \tfrac{1}{2}\bigl(T \pm \sqrt{T^2-4D}\bigr)$. For each $\lambda$, solve $(A-\lambda I)\mathbf{v}=\mathbf{0}$; for a $2\times 2$ matrix one row is enough, e.g. $\mathbf{v} = \begin{pmatrix} b \\ \lambda - a\end{pmatrix}$ when $b \neq 0$.

Useful checks: $\lambda_1 + \lambda_2 = T$ and $\lambda_1\lambda_2 = D$. If $T^2 - 4D < 0$ the eigenvalues are complex and no real direction is left unturned.
