📐 How eigenvectors build the solution ▼

Try $\mathbf{x}(t) = e^{\lambda t}\mathbf{v}$. Then $\mathbf{x}' = \lambda e^{\lambda t}\mathbf{v}$ and $A\mathbf{x} = e^{\lambda t}A\mathbf{v}$, so it is a solution exactly when $A\mathbf{v} = \lambda\mathbf{v}$. These are the straight-line solutions: they stay on the eigenvector's line, moving out if $\lambda > 0$ and in if $\lambda < 0$.

Distinct real eigenvalues: every solution is a combination $\mathbf{x}(t) = c_1 e^{\lambda_1 t}\mathbf{v}_1 + c_2 e^{\lambda_2 t}\mathbf{v}_2$; the constants come from $\mathbf{x}(0) = c_1\mathbf{v}_1 + c_2\mathbf{v}_2$.

Complex eigenvalues $\lambda = \alpha \pm \beta i$ with $\mathbf{v} = \mathbf{p} \pm i\mathbf{q}$: the real and imaginary parts of $e^{\lambda t}\mathbf{v}$ give two real solutions, and $e^{\alpha t}$ decides whether the orbit spirals in ($\alpha < 0$), out ($\alpha > 0$), or closes into an ellipse ($\alpha = 0$).

Repeated eigenvalue with one eigenvector: the second solution is $e^{\lambda t}(t\,\mathbf{v} + \mathbf{w})$, where $\mathbf{w}$ solves $(A - \lambda I)\mathbf{w} = \mathbf{v}$.
